# FormyCareer Mobile

Flutter mobile app for FormyCareer.

## Development

- Install Flutter SDK compatible with Dart `^3.11.4`
- Run app:
  - `flutter pub get`
  - `flutter run`

## Android release for Google Play

Follow:
- `RELEASE_PLAYBOOK.md`

Key files:
- `android/app/build.gradle.kts`
- `android/key.properties.example`
- `release/play/data-safety-checklist.md`
- `release/play/store-listing-template.md`
- `release/play/testing-smoke-checklist.md`
- `release/play/staged-rollout-runbook.md`
